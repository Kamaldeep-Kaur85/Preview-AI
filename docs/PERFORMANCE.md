# PreView AI — Performance Benchmarks

> All measurements are explicitly labeled by hardware, backend, and methodology.
> Run `python -m app.benchmark` to reproduce CPU figures.

## 1. CPU Inference (Verified)

**Hardware**: Intel(R) Core(TM) i7-10610U CPU @ 1.80GHz  
**Architecture**: AMD64 (x86/x64)  
**OS**: Windows 11  
**Backend**: ONNX Runtime `CPUExecutionProvider`  
**Model**: `preview_impact_predictor.onnx` (12.3 KB)  
**Precision**: FP32  
**Iterations**: 100 timed runs, 10 warmup  

| Metric | Value |
|:---|:---|
| P50 (Median) Latency | ~0.10–0.14 ms |
| P95 Latency | ~0.20 ms |
| Average Latency | ~0.14 ms |
| Min Latency | ~0.10 ms |
| Throughput | ~32,000–34,000 inf/sec |
| Model Load Time | ~31–33 ms |
| Peak Memory | ~0.01–3.05 MB |

> **Source**: `docs/SNAPDRAGON_BENCHMARK.md` Section 2 (Local Host Run Information)

## 6. Reproducing Benchmarks

```bash
# Run hardware benchmark (CPU on any machine)
python -m app.benchmark

# Run model evaluation
python -m app.evaluation

# Run AI Hub compliance check
python -m app.ai.ai_hub_manager

# Run diagnostics
python -m app.main --diagnostics
```
